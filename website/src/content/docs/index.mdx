Ink is intended to add a compact interactive editing step to terminal workflows. The design reserves standard output for the accepted value while the interface talks directly to the controlling terminal.

## What exists today

The repository contains a Rust command-line bootstrap and behavioral specifications. It can parse the proposed commands and generate completions, but `input` and `textarea` currently exit with a “not implemented” error. These pages describe the target contract so it can be reviewed while implementation proceeds.

## Design principles

- **Composable:** UI traffic stays off standard output.
- **Predictable:** command-line options override user configuration, which overrides built-in defaults.
- **Text-correct:** edits operate on visible grapheme clusters instead of bytes.
- **Recoverable:** terminal state must be restored after acceptance, cancellation, errors, or caught panics.
- **Legible:** mode names are visible as text and do not rely on color alone.
