## Built for terminal workflows

Use `ink input` for compact values and `ink textarea` for prose or structured multiline text. Seed either prompt from `--value` or a pipe, edit with familiar Vim motions, and pass the accepted result to the next command. Bundled themes, semantic color overrides, shell completions, and validated configuration keep Ink at home in existing terminal setups.

## Design principles

- **Composable:** UI traffic stays off standard output.
- **Predictable:** command-line options override user configuration, which overrides built-in defaults.
- **Text-correct:** edits operate on visible grapheme clusters instead of bytes.
- **Recoverable:** terminal state must be restored after acceptance, cancellation, errors, or caught panics.
- **Legible:** mode names are visible as text and do not rely on color alone.
